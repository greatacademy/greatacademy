# 未成年人数据

> [English](minors-data.md) | 简体中文

本文档规定 Great Academy 如何处理未成年人写下和说出的内容：谁可以用哪项功能，需要谁同意，保存什么、保存多久，以及谁会收到这些数据。依据是多邻国公开的说明和 2026 年 11 月查阅的法律。

**状态。** 这些都还没有实现，也没有律师审阅过。这是 [E0.3](english-development-plan.zh-CN.md#2-阶段-0准备) 带给法律顾问的工程方案，不是法律意见。标为*初始值*的数字是我们自己定的，不是法律规定的。

## 1. 原则

1. **课程用不到的就不收集。** 没有收集的数据，不需要同意、保存规则或删除。
2. **收集之前取得监护人同意，每个用途分别同意。** 拒绝可选功能，绝不影响基础课程。
3. **服务端默认拒绝。** 只有这位学习者在这个市场有同意记录时，功能才运行。
4. **每种数据都有删除日期，** 包括派生数据：转写、引用学习者原文的反馈，以及供应商处的副本。
5. **未成年人的数据只用于教这位未成年人。** 不训练任何模型，无论是我们的还是供应商的，也绝不用于广告。

## 2. 多邻国的做法

读自[其隐私政策](https://www.duolingo.com/privacy)，最后修订于 2026 年 5 月 26 日。这是政策上写的内容，不是我们在应用中观察到的；多邻国这样规模的公司这样做，也不说明这样做合法。

| 方面 | 多邻国的做法 |
| :--- | :--- |
| 谁算儿童 | 美国未满 13 岁，其他地方未满当地数字同意年龄。注册时询问年龄；政策没有描述任何核实手段 |
| 儿童账号 | 用户名不关联真实姓名；不要姓名、邮箱或电话。儿童第一次退出登录时询问家长邮箱，然后向家长发送通知，说明如何访问、修改或删除数据 |
| COPPA 立场 | 儿童数据仅为服务的内部运营而收集 |
| 儿童语音 | 不用于产品改进。一般规则仍照常适用：音频可能发送给 Google、Apple 或 AWS 等识别服务商。口语活动可以跳过 |
| 其他人的语音 | 除非在设置中关闭，否则用于产品改进。绝不用于声音克隆 |
| AI 功能 | 文本和音频可能发送给 OpenAI、Google 等供应商，合同禁止供应商用于自身目的。多邻国可能保存录音和转写，并用它们训练自己的模型。提醒用户不要提交个人信息。政策没有说明儿童能否使用这些功能 |
| Math Tutor | 音频只发给 Apple 识别，然后立即删除；转写保留 |
| Duolingo ABC（面向低龄儿童） | 由家长设置，家长选择是否启用口语。语音数据留在手机上，使用 Apple 的识别，不传给多邻国 |
| 用户之间的文字 | 儿童只能发送预设评论。在排行榜中显示随机假名 |
| 未满 16 岁 | 没有个性化广告、第三方行为追踪或第三方分析。儿童的会话回放也关闭 |
| 保存期限 | 一般保存到账号删除，音频和转写没有写明期限；匿名数据无限期保存 |
| 学校 | 教师可以看到学生的姓名和邮箱，并能以学生身份登录；学生可以退出班级 |

**我们采用的：** 不含身份信息的账号、用户之间用预设文字代替自由文字、联赛中的假名、可跳过的语音、禁止声音克隆，最重要的是 Duolingo ABC 由家长启用语音，以及 Math Tutor 的立即删除。

**我们不采用的：**

- **事后通知。** 多邻国的账号之所以成立，是因为它主张几乎不收集任何东西。我们不能这样主张：写作和发音要发给供应商，并形成学习者的记录，所以必须先取得同意。
- **保存到账号删除。** 这很难符合 COPPA 的保存规则和第 3 节的两起 FTC 案件。
- **用学习者的语音训练模型，** 即使可以退出。
- **把"请勿提交个人信息"当作防护措施。** 孩子总会写下名字，所以由系统过滤。

Common Sense 给多邻国的评级是"Warning"，出自[一份未注明日期的评估](https://privacy.commonsense.org/evaluation/duolingo)。搜索结果引用的一份学校影响评估我们无法读取，也没有确认儿童能否使用 Video Call。

## 3. 法律的要求

| 制度 | 与我们相关的内容 |
| :--- | :--- |
| **COPPA**（美国，未满 13 岁），修订规则自 2026 年 4 月 22 日起全面生效 | 收集前须取得可验证的家长同意。[声纹属于个人信息](https://www.law.cornell.edu/cfr/text/16/312.2)。面向儿童、受众混合的服务，须在收集任何内容之前以中立方式询问年龄，不设默认值。[非必要披露须单独同意](https://www.law.cornell.edu/cfr/text/16/312.5)，只有不向第三方披露时才能用 email plus 或 text plus。[须有公布的书面保存政策并写明删除时限；不得无限期保存](https://www.law.cornell.edu/cfr/text/16/312.10)。FTC [认为](https://www.dataprotectionreport.com/2025/06/ftcs-coppa-rule-changes-include-ai-training-consent-requirement/)为训练 AI 而披露不属于必要披露 |
| **FTC 语音政策**（2017） | 音频仅用于代替书面文字、短暂保存且无其他用途时，[不予执法](https://www.ftc.gov/news-events/news/press-releases/2017/10/ftc-provides-additional-guidance-coppa-voice-recordings)。给发音或流利度打分是另一种用途，所以我们不依赖这项政策（我们的理解，待法律顾问确认） |
| **FTC 诉 Amazon（Alexa，2023）** | [指控](https://www.ftc.gov/news-events/news/press-releases/2023/05/ftc-doj-charge-amazon-violating-childrens-privacy-law-keeping-kids-alexa-voice-recordings-forever)：无限期保存录音并用于训练语音识别；删除请求留下了转写。拟议罚款 2500 万美元 |
| **FTC 诉 Edmodo（2023）** | [一项教育科技命令](https://www.insideprivacy.com/childrens-privacy/ftc-announces-coppa-settlement-against-ed-tech-provider-including-strict-data-minimization-and-data-retention-requirements/)：保存计划最长一年，此前不活跃两年才删除的做法被认定缺乏正当理由。[学校不能代为同意](https://thejournal.com/articles/2023/06/15/ftc-fines-edmodo-for-illegal-use-of-student-data-and-outsourcing-compliance-to-schools.aspx)广告或机器学习用途 |
| **美国各州** | [许多州现在保护所有未满 18 岁者](https://www.onetrust.com/blog/us-childrens-data-laws-and-consent-what-businesses-need-to-know-in-2026)，弗吉尼亚等地还要求[对未成年人数据进行评估](https://www.insideprivacy.com/childrens-privacy/state-and-federal-developments-in-minors-privacy-in-2026/)。没有逐州核查；伊利诺伊州的生物识别法完全没有核查 |
| **GDPR** | 同意年龄[因国家而异，在 13 到 16 岁之间](https://sota.io/blog/gdpr-art-8-childrens-consent-age-verification-parental-authorization-digital-services-developer-guide-2026)，我们没有从完整的官方表格确认。声纹[用于识别身份时](https://www.pearlcohen.com/edpb-issues-draft-guidance-on-virtual-voice-assistants/)属于特殊类别数据（指南草案）；我们绝不通过声音识别任何人。预计需要影响评估和欧盟代表（凭记忆，待法律顾问确认） |
| **英国儿童守则** | 对可能被未满 18 岁者访问的服务提出 [15 项标准](https://www.taylorwessing.com/en/insights-and-events/insights/2020/02/ico-publishes-age-appropriate-design-code-of-practice)，默认采用高隐私设置。通过 2020 和 2021 年的二手资料阅读；ICO 的页面无法获取，需要核查后续变化 |
| **欧盟 AI 法案** | [附件 III](https://artificialintelligenceact.eu/annex/3/) 把评估学习成果的 AI（包括结果用于引导学习时）列为高风险。所以决定掌握与否的 AI 判定很可能属于高风险。[据报道](https://pasqualepillitteri.it/en/news/5190/digital-omnibus-ai-act-eu-parliament)自 2027 年 12 月起适用；最终通过尚未确认。在教育中推断情绪被禁止（凭记忆，待法律顾问确认） |
| **中国** | 《个人信息保护法》：[未满 14 岁者的所有个人信息都是敏感信息，需要监护人同意和专门规则](https://www.mofo.com/pdf/resources/insights/210908-chinas-personal-information-protection-law)。[《未成年人网络保护条例》](https://www.gov.cn/zhengce/content/202310/content_6911288.htm)，未满 18 岁：不得因拒绝可选同意而拒绝基本功能（第 32 条）、监护人访问和删除（第 34 条）、泄露报告（第 35 条）、员工访问须审批并留痕（第 36 条）、每年合规审计（第 37 条）。中国大陆不是目标市场，但如果在当地提供服务，这些都适用 |

尚未研究：香港、台湾、新加坡、加拿大、澳大利亚、日本、韩国和巴西。其中几个很重要，因为我们有许多学习者说中文。适用哪里的法律取决于学习者住在哪里，而不是说什么语言。

**我们的服务算作面向儿童。** 课程从低年级开始，英语的首个切片面向 3 到 8 年级。单靠询问年龄并不能脱离 COPPA 的范围。

## 4. 年龄段

| 年龄段 | 对象 | 账号 |
| :--- | :--- | :--- |
| **儿童** | 低于市场的同意年龄（`markets` 表）：美国和英国 13 岁，欧盟最高 16 岁，中国 14 岁 | 由监护人创建；没有邮箱或真实姓名 |
| **青少年** | 从该年龄到 17 岁 | 自己的账号，默认保护设置（第 6 节） |
| **成年人** | 18 岁及以上 | 与现在相同 |

- **询问。** 注册时首先询问出生年月，不设默认值，也不提示原因，并询问国家，根据连接预填。低于同意年龄的学习者转到监护人流程，在该浏览器上重试不会改变答案。
- **存储。** 保存年龄段、其结束日期和国家，不保存出生日期。
- **国家未知：** 同意年龄按 16 岁。
- **长大之后。** 年龄段结束不会自动放宽任何设置。学习者会收到通知并重新选择。
- **不用证件核实。** 向儿童收集证件会造成我们正要避免的风险。证明身份的是监护人，不是儿童。

## 5. 账号与同意

**监护人优先。** 成年人创建自己的账号，再用用户名和密码添加孩子的档案。孩子永远不提供邮箱或姓名。这与现在由学习者邀请监护人的关联方式相反，后者保留给青少年。

**每个用途都有自己的同意：**

| 范围 | 启用 | 发给供应商 | 方式 |
| :--- | :--- | :--- | :--- |
| `basic` | 课程和规则判定的答案 | 没有，托管和邮件除外 | Email plus；试点用签字表格 |
| `writing` | AI 判定的写作（E3） | AI 模型 | 签字表格或支付卡交易 |
| `speech` | 录音，S2 到 S5（E4、E5.1） | 语音服务、AI 模型 | 同上 |
| `conversation` | S6（E5） | 语音服务、AI 模型 | 同上；除非法律顾问同意，儿童关闭 |
| `research` | 由人评分的校准集 | 评分人员 | 签字表格，每次收集分别签署 |

- 同意记录只追加：学习者、范围、监护人、方式、通知版本、国家、授予和撤回时间。
- 除 `basic` 外，监护人可以拒绝或撤回任何范围，并继续使用课程。需要缺失范围的任务不会提供，学习者绕过它继续学习，[设计](english-curriculum.zh-CN.md)对语音已有同样的要求。
- 撤回时同时删除该范围产生的数据。
- 新增供应商或用途，需要新的通知版本和新的同意。
- 青少年自己同意，`speech` 和 `conversation` 在其开启前保持关闭。如果某个市场要求青少年也需监护人同意，由该市场的行说明。

**学校。** 学校不能同意其教育目的之外的任何事情，我们也没有与学校签订协议。在法律顾问审阅之前，不向未成年人提供班级和教师角色。

## 6. 各年龄段的功能

| 功能 | 儿童 | 青少年 |
| :--- | :--- | :--- |
| 课程、复习、测验、阅读 | 需要 `basic` | 开启 |
| AI 判定的写作 | 需要 `writing`，题目不询问个人情况 | 开启，事先通知 |
| 录音语音 | 需要 `speech` | 开启前关闭 |
| 对话 | 关闭 | 开启前关闭 |
| 联赛 | 关闭；以后开放时用随机名称且没有资料页 | 开启前关闭，只显示用户名 |
| 用户之间的自由文字 | 绝不 | 绝不 |
| 广告、第三方追踪、会话回放 | 绝不 | 绝不 |
| 训练任何模型、声纹、声音克隆、推断情绪或性格 | 绝不 | 绝不 |

当 AI 在判定或与学习者交谈时，我们用学习者能懂的话告诉他们。

## 7. 文本

- **题目避开个人话题。** 题目询问给定文本或虚构情境，而不是"描述你的家庭"。
- **先过滤。** 文本离开平台或交给人阅读之前，邮箱、电话、地址、账号名和疑似姓名都替换成占位符。每次上线前抽样检查过滤器；它不可能拦住所有内容，不能把漏过的内容视为无害。
- **模型调用。** 只用第 10 节的供应商，网关不记录文本，不做缓存。提示词只含过滤后的文本，不含账号数据。
- **事件不含文本。** 重放需要的是分数，所以事件日志只存 ID 和分数。回答放在 `answer` 或写作表中，到期删除不影响学习者状态。
- **阅读文本的人。** 试点报告汇总回答，不带学习者身份。员工访问须经审批并留痕。
- **写作或语音中的伤害迹象** 进入明确的审查流程。告知谁、何时告知因市场而异，属于法律顾问的问题（第 12 节）。

## 8. 语音

1. **优先本地。** 设备能自行识别语音时，音频不离开设备，如 Duolingo ABC。
2. **否则流式传输，不存储。** 优先选用不保留数据的实时服务。[微软说明](https://learn.microsoft.com/legal/cognitive-services/speech-service/speech-to-text/data-privacy-security)实时识别和发音评估不保留客户数据。
3. **需要文件时，** 用短期 URL 上传到 R2，判定后立即删除，生命周期规则在一天内清除遗留文件。语音服务按设计不保存音频。
4. **录音之前：** 学习者能看到录音提示，可以跳过且不受惩罚。不在后台录音，题目不要求说出姓名。
5. **绝不：** 把声音存为档案、识别说话人，或推断情绪、健康状况或年龄。
6. **校准。** 儿童录音片段（E4.6）只在 `research` 下收集，用单独的表格说明谁来评分、何时销毁，绝不与学习者的录音混在一起。

## 9. 保存与删除

| 数据 | 儿童 | 青少年 | 到期之后 |
| :--- | :--- | :--- | :--- |
| 音频 | 判定为止，最长 1 天 | 相同 | 删除 |
| 转写 | 30 天（*初始值*） | 30 天（*初始值*） | 保留分数 |
| 对话转写 | 不保存 | 30 天（*初始值*） | 删除 |
| `answer.response` 中的自由文本 | 90 天（*初始值*） | 1 年（*初始值*） | 清空；保留对错 |
| 作文及引用作文的反馈 | 1 年（*初始值*） | 1 年（*初始值*） | 删除；保留分数 |
| 进度：事件、状态、答案对错 | 活跃期间 | 活跃期间 | 随账号删除 |
| 日志中的 IP 地址 | 30 天 | 30 天 | 删除 |
| 同意记录 | 账号存续期，再加法律顾问确定的期限 | 相同 | 删除 |
| 不活跃账号 | 12 个月（*初始值*），然后通知，再过 30 天 | 相同 | 删除 |

- **删除意味着处处删除。** 一个函数覆盖数据库表、转写、反馈、R2 和供应商副本，并有测试检查被删除学习者不留任何数据。备份在规定的时间窗口内过期。这里点名转写，就是因为 Alexa 案。
- **监护人可以自己操作。** 他们可以按数据种类查看、导出和删除，也可以删除整个档案，不需要发邮件。拒绝请求须书面说明理由。
- **匿名化不等于豁免。** 文本和语音很难匿名化，所以都不作为"匿名数据"保存。只保留汇总计数。
- 公布的保存政策写明目的、业务需要和这些时限，符合 COPPA 的要求。

## 10. 供应商

只有合同和设置满足以下全部条件，供应商才能收到未成年人的数据，并记入登记表，注明核查日期：

- 其条款允许处理未成年人数据，我们满足其条件。
- 零保留或写明的短期保留，且不用于训练。
- 有数据处理协议和合法的跨境传输机制。
- 指定了区域。

| 供应商类型 | 已知情况 | 待核查 |
| :--- | :--- | :--- |
| OpenAI API | 对未满 13 岁或同意年龄者[要求零数据保留](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance)和适龄防护 | 合同 |
| Anthropic API | [允许组织服务未成年人](https://support.claude.com/en/articles/9307344)，要求年龄确认、内容审核、监控、AI 披露和公开的合规声明 | 我们能否获得零保留 |
| Azure AI Speech | 见第 8 节 | 合同、区域 |
| 其他语音和 AI 供应商、pi-ai 路由、AI Gateway | 未核查 | 使用前逐一核查；路由可能更换供应商，所以未成年人的路由是固定的 |
| Cloudflare、PostgreSQL 托管、Resend | 未核查 | 协议、区域 |

## 11. 代码中的执行

- **`learner`** 增加年龄段、年龄段结束日期和国家。新的只追加 **`consent`** 表保存第 5 节的内容。
- **`markets`** 是 `libs/api` 中的纯数据表，给出每个国家的同意年龄、允许的功能以及是否提供服务。未列出的国家按最严格的一行处理。
- **唯一的关口。** `StartTask` 和所有接受文本或音频的调用都向 `libs/api` 查询学习者的能力，不满足就拒绝。`nextTasks` 以数据形式接收允许的任务类型，使引擎保持纯净、不涉及具体学科。
- **保存期限** 由每日 Cron Trigger 执行，可以用明确的时间测试。
- **日志** 只含 ID，绝不含回答或转写。有测试让带标记的文本走完任务，并断言它没有出现在任何日志或事件中。
- **员工访问** 未成年人文本要通过有审计的工具，不能在生产环境直接写 SQL。

**目前的差距。** 注册没有年龄问题，还要求真实姓名和邮箱。没有隐私通知或条款页面。`answer.response` 以明文永久保存。监护人由学习者邀请，且不能删除数据。账号删除会级联到学习者数据，这是个好的基础。
