# 体验

> [English](experience.md) | 简体中文

本文描述 Great Academy 如何呈现给学习者和监护人：哪些属于学科、哪些属于账户，网页和应用里的页面如何安排，以及谁做哪些决定。页面背后的算法见[学习引擎](learning-engine.zh-CN.md)，内容见[内容](content.zh-CN.md)。

## 1. 原则

1. **学科是独立的空间。** 数学和英语分开学习：每个学科有自己的当前课程、任务、进度、记录、目标和知识档案。属于某个学科的每个页面都标明是哪个学科，学习者始终知道自己在哪里。
2. **账户是共享的。** 个人资料、方案、隐私、外观、语言、监护人和联赛在所有学科中相同。
3. **学习者学习，监督人决定。** 学哪门课、何时重新诊断、是否重置知识档案、每周目标和截止日期，由学习者的监督人决定（§5）。不是自己监督人的学习者能看到这些决定和由谁决定，但不能更改。
4. **决定要说明何时适用。** 每个决定都说明它改变什么、什么时候有帮助。无法撤销的决定会再问一次。
5. **页面从顶部打开。** 进入页面时既不聚焦输入框，也不滚动：学习者先看到标题和题目。只有学习者有所操作时，焦点才移动、页面才滚动，例如对话中出现新字幕，或针对学习者刚做的选择再问一次。

## 2. 学科

**标识。** 学科声明一个 `mark`（一两个字符：数学是 `∑`，英语是 `Aa`）和一个 0 到 360 的 `hue`（[内容 §1](content.zh-CN.md#1-概念)）。`libs/design` 中的 `subjectColors(hue, scheme, contrast)` 把色相变成学科标签、底色和进度条的颜色，与调色板遵守同样的对比度目标，并与判定色相距至少 20 度。学科的颜色标明学习者所在的位置；调色板的强调色仍是操作的颜色。

**学科标签**是带底色方块上的标记加学科名称。它位于每个学科页面页头的开头、任务的顶栏、学科切换器中，以及在学科之外显示的任何课程或知识点前面。

**哪些属于学科：**

| 每个学科独立 | 账户共享 |
| :--- | :--- |
| 当前课程和以往课程 | 个人资料、密码、邮箱 |
| 任务、学习过程及其记录 | 方案和付费 |
| 知识点地图和知识档案 | 隐私、年龄和数据 |
| 诊断 | 外观和语言 |
| 每周目标、速度和预计完成 | 监护人 |
| 截止日期 | 联赛，按所有学科的 XP 计 |

XP 在某个学科中获得，也计在该学科。账户的总数是各学科之和，联赛和账户页显示它。联赛页列出本周同段位学习者的排名，用一条线标出升段区的终点，另一条标出降段区的起点，并显示本周还剩几天。

**名字。** 每个账号（包括儿童账号）都有名字和用户名，注册或监护人添加孩子时填写，都在个人资料中修改。名字不公开：只有本人及其监护人能看到。用户名和邮箱一样可以登录，也是联赛显示的唯一名称；儿童账号没有邮箱，只用用户名登录。联赛设置只决定是否参加。

**当前学科。** 学习者登录或打开应用时，进入最后学习的学科，不论在哪台设备上学的：即课程最近做过任务或最后选课的那个学科。此后打开的学科一直是当前学科，直到页面重新加载、应用关闭或退出登录；网页的课程目录打开这个浏览器最后打开的学科。

## 3. 学科的页面

每个学科有三个页面，网页和应用相同：

- **学习**：现在做什么。课程及其进度、进行中的任务或接下来的任务、诊断或其报告、课程需要的前面课程知识点比自己的还多时改从前面课程开始的提议（[学习引擎 §9](learning-engine.zh-CN.md#9-诊断)），以及最近完成的几个任务；旁边是该学科的累计 XP 和今天的 XP、每周目标和最近 14 天、可比较不同速度的预计学完时间，以及本周联赛。
- **进度**：学到哪里了。课程的知识点地图，旁边是与学习页相同的目标和预计学完卡片；已完成任务的记录从页头打开。
- **课程**：在学什么。当前课程及其大纲、该学科的其他课程，以及与之相关的决定：换课程、重新诊断和重置知识档案。

知识点页面和任务属于其课程的学科，并显示该学科的标签。

**一次任务**在网页和应用中都在离开按钮下方有同样的步骤条。课程的步骤条按知识点分组，每组的讲解、例题和各道题各是一段；通过这个知识点还需要的题显示为尚未开始，答错后追加的题在问到时才出现。其他任务每道题一段。判定后的段变为绿色或红色，分步题的段按小问分开。走过的每一步都可以从步骤条、两侧箭头或 ← 和 → 再次打开，只读：讲解、带完整解答的例题，或带作答答案和判定的题；当前这一步在此期间保留已写的内容。讲解和例题各是单独的一步，例题直接显示解答。答案的判定出现在题目卡片里，用判定的颜色，带说明、正确答案和解答，答错时解答展开；点“继续”或按回车进入下一步，手机上“继续”固定在屏幕底部。复习题的参考放在卡片里的“?”后面，并说明查看的代价。分步题的情境固定在各小问上方，可以收起；每一小问只问它自己的问题，放在已答的小问下方。

**测验**按考试的方式作答：有带编号的题目列表，点击、两侧箭头或 ← 和 → 可以打开任意一题，并显示已答题数和剩余时间。每个答案只保存、不判定，交卷前都可以修改，只有已开始分步作答的分步题除外。交卷前先确认，说明还有几题未作答、还剩多少时间；时间用完时，已写的答案会被保存并自动交卷。之后结果页列出每道题的难度和判定。

**任务结果**显示得分、获得的 XP 与该任务满分 XP 的对比，然后是每道题：所属知识点、所属学习点（课程的题目排在各自学习点标题之下）、用时、测验中是否超时、所给答案，答错时还有正确答案和解答。复习题提供它的课程内容作为参考，并说明查看后答对只计一半分数；打开后，参考一直显示在题目上方。分步题在作答时显示“第 2 问，共 3 问”，结果中逐问列出，每一问排在它所练的知识点之下。课程的结果列出它所依赖的知识点，逐一标明是否已掌握；未通过的课程的结果以链接列出在它再次出现之前要复习的关键先修知识点。任务记录打开的是同样的结果。

**任务记录**按天分组，最近的在前，每天显示当天获得的 XP；每个任务显示获得的 XP 与满分 XP 的对比，负数用红色。**课程卡片**列出它所依赖的知识点，逐一标明是否已掌握。**知识点地图**按掌握的牢固程度为每个已学会的知识点着色：用配色主色的六档深浅，从刚学会到通过多次间隔复习，整张地图读起来像热力图；未学的知识点是空心圆点，可以接着学的用主色描边，课程等待复习后再学的用红色描边。已学会的知识点要么无需复习，要么待复习，二者不会同时出现，都计为已学会；待复习的外加一圈琥珀色细环并带标签，可以学习的和等待中的也带标签，记忆程度在悬停时显示。每个单元的开头显示已学会的知识点数，以及一条每个知识点一段的进度条：最牢固的排在前面，未学的留空，长度与课程中最大的单元成比例。图例先给出已学会的知识点数和深浅色阶，再列出其他状态。每一项都会解释其含义：有指针的设备上悬停即可看到；在图例中轻点或按下名称也会显示，因此手机上同样可见；知识点自己的页面在标题下写明。每个单元编号为 1、2、3，单元下的每个模块编号为 1.1、1.2。学习页和课程页上课程的进度条也按同样的深浅着色，最牢固的在前，旁边显示课程已学会的百分比，向下取整，因此 100% 意味着全部知识点都已学会；学习页在进度条下不再显示其他内容，点击课程标题打开进度页。悬停在进度条上会解释它；轻点或点击进度条会在页面上方弹出（宽屏是弹出框，手机是从底部升起的面板），不会推动下面的内容，其中以选项卡显示课程序列，并显示所选课程每一档深浅各有多少个知识点，以及按编号列出的各单元，每个单元有自己的着色进度条和百分比。单元下面和进度页上各有一个按钮打开课程的**知识点图**，与 Math Academy 的百分比按钮一样：在整个屏幕上，课程的每个知识点是一个方框，位于它所依赖的本课程知识点上方，按进度地图的深浅和标记着色，并用线连到直接依赖它的知识点；课程之外的先修知识点会被穿过，连到它下面最近的本课程知识点。知识点图打开时适合屏幕大小；拖动可移动，滚轮、双指或角上的按钮可缩放，指向一个知识点（手机上轻点它）时，它所依赖的知识点会亮起。在网页上，当前课程的知识点可以打开它的页面；应用中没有知识点页面。课程序列列出最多三门以往学过的课程（最早的在前）、当前课程，以及学习者路线上最多三门接下来的课程（路线由系统推断，不显示）；学习者若是从目标课程退回的，目标课程也在其中（[学习引擎 §9](learning-engine.zh-CN.md#9-诊断)）；进度页的地图上方也有课程序列，选中其他课程时，用同一份学习状态显示那门课的地图，其中的知识点不带链接，因为知识点页面针对的是当前课程。课程学完后会自动接续，与 Math Academy 一样：学习者升入路线上的下一门课，在开始新课程的任务之前，学习页会说明学完的是哪门课；复习照常进行。只有后面没有课程的课程会保持不变，此时学习页表示祝贺，并引导选择课程的人去课程目录。

**学科切换器**从页头的学科标签打开。它列出学习者的学科，每个学科附带当前课程和今天的 XP 对比目标，并提供尚未开始的学科，点进去是该学科的课程目录。最后一项是**课程目录**，这样命名是为了和学科的课程页区分开。

## 4. 布局

**网页。**

| 路径 | 页面 |
| :--- | :--- |
| `/` | 未登录是落地页；已登录是当前学科的学习页 |
| `/{subject}` | 学习 |
| `/{subject}/progress` | 进度 |
| `/{subject}/history` | 已完成任务的记录 |
| `/{subject}/course` | 课程 |
| `/{subject}/topics/{topic}` | 重读一个知识点 |
| `/session/{id}` | 一个任务 |
| `/courses` | 公开的课程目录，每个学科一个标签页 |
| `/courses/{course}` | 课程的公开页面 |
| `/settings` | 账户 |
| `/guardian`、`/guardian/{learner}` | 监护人的学习者，以及其中一位 |
| `/league` | 联赛 |

页头包括标志、带切换器的学科标签、学科的三个页面，右侧是联赛和账户菜单。在学科之外（课程目录、账户、联赛），学科标签换成页面名称。

**应用。** 在桌面上，侧边栏以学科标签开头，点击打开切换器，接着是学科的三个页面；底部点学习者的名字打开账号菜单，与 web 的相同（课程目录、联赛、你关注的学习者、设置、退出登录），旁边是设置按钮。在手机上，顶栏标题是学科标签，标签栏是学习、进度、课程和我，「我」里是账户。设置里的「账号安全」列出修改密码、退出登录和删除账号；两个表单各自作为单独的页面打开，web 与应用相同。

**课程目录。** 课程目录一次显示一个学科，由顶部的标签页选择；其中的书架（年级、考试、大学）是该学科自己的。其中每门课程都打开它的课程页，学习者正在学的课程也一样。课程页用学科标签标明所属学科。

**课程路线图。** 在网页和 App 上，课程目录的书架下方把该学科的课程画成一张图：最基础的课程在最下面，每门课比它所依赖的最高那门课高一行，每门课用线连到直接依赖它的课程。一门课经由另一门课才能到达的课程，只经由那门课相连。每个方框打开该课程的课程页；指向一个方框时，它依赖的课程会亮起，学习者正在学的课程以实色填充。手机没有指针，第一次点方框会让它亮起，再点一次打开该课程。比屏幕宽的图在框内横向滚动。

## 5. 监督

学习者的**监督人**替他们做决定：

- 成年人监督自己；
- 未成年人由其监护人监督，任何一位监护人都可以决定；
- 没有监护人的青少年在有监护人关注之前监督自己。儿童总有监护人，账户由监护人创建。

**学科的决定：**

| 决定 | 位置 | 何时有帮助 |
| :--- | :--- | :--- |
| 换课程 | 课程 | 课程太容易或太难，或有了新目标（某个年级、某场考试）。进度会保留；确认时显示新课程中哪些知识点已经掌握，以及预计完成时间。 |
| 重新诊断 | 课程 | 中断超过十周之后，或在 Great Academy 之外学过之后。诊断判定的知识点会重新提问；课时学会的知识点保留，由复习来纠正。执行前会再问一次。 |
| 重置知识档案 | 课程 | 记录不可信时：做题借助了外部帮助或工具，或档案与实际掌握相差很远。推断从重置时重新开始；记录和 XP 保留。执行前会再问一次。 |
| 每周目标 | 学习、进度 | 该学科一周中每天要获得的 XP。 |
| 截止日期 | 学习、进度 | 课程应在何时学完；预计完成会说明当前速度是否足够，以及每天需要多少 XP。 |

监护人在学习者的页面上做这些决定。该页面有同样的学科切换器，以只读方式显示学习者的学习、进度和课程页面，决定的操作可用。不是自己监督人的学习者能看到每个决定的当前值和「由你的监护人决定」，没有操作按钮。

## 6. 监护人

监护人的列表显示每位学习者及其各学科的标签，以及每个学科今天和本周的 XP 对比目标。学习者的页面打开最近学习过的学科。
