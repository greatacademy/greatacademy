# 体验

> [English](experience.md) | 简体中文

本文描述 Great Academy 如何呈现给学习者和监护人：哪些属于学科、哪些属于账户，网页和应用里的页面如何安排，以及谁做哪些决定。页面背后的算法见[学习引擎](learning-engine.zh-CN.md)，内容见[内容](content.zh-CN.md)。

## 1. 原则

1. **学科是独立的空间。** 数学和英语分开学习：每个学科有自己的当前课程、任务、进度、记录、目标和知识档案。属于某个学科的每个页面都标明是哪个学科，学习者始终知道自己在哪里。
2. **账户是共享的。** 个人资料、方案、隐私、外观、语言、监护人和联赛在所有学科中相同。
3. **学习者学习，监督人决定。** 学哪门课、何时重新诊断、是否重置知识档案、每周目标和截止日期，由学习者的监督人决定（§5）。不是自己监督人的学习者能看到这些决定和由谁决定，但不能更改。
4. **决定要说明何时适用。** 每个决定都说明它改变什么、什么时候有帮助。无法撤销的决定会再问一次。

## 2. 学科

**标识。** 学科声明一个 `mark`（一两个字符：数学是 `∑`，英语是 `Aa`）和一个 0 到 360 的 `hue`（[内容 §1](content.zh-CN.md#1-概念)）。`libs/design` 中的 `subjectColors(hue, scheme, contrast)` 把色相变成学科标签、底色和进度条的颜色，与调色板遵守同样的对比度目标，并与判定色相距至少 20 度。学科的颜色标明学习者所在的位置；调色板的强调色仍是操作的颜色。

**学科标签**是带底色方块上的标记加学科名称。它位于每个学科页面页头的开头、任务的顶栏、学科切换器中，以及在学科之外显示的任何课程或知识点前面。

**哪些属于学科：**

| 每个学科独立 | 账户共享 |
| :--- | :--- |
| 当前课程和以往课程 | 个人资料、密码、邮箱 |
| 任务、学习过程及其记录 | 方案和付费 |
| 知识点地图和知识档案 | 隐私、年龄和数据 |
| 诊断 | 外观和语言 |
| 每周目标、速度和预计完成 | 监护人 |
| 截止日期 | 联赛，按所有学科的 XP 计 |

XP 在某个学科中获得，也计在该学科。账户的总数是各学科之和，联赛和账户页显示它。

**当前学科。** 每个客户端记住最后打开的学科。已登录的学习者打开它，否则打开最近学习过的学科。

## 3. 学科的页面

每个学科有三个页面，网页和应用相同：

- **学习**：现在做什么。进行中的任务、接下来的任务、诊断或其报告，以及今天的 XP 对比该学科的目标。
- **进度**：学到哪里了。课程的知识点地图、最近 14 天的 XP 和每周目标、预计完成和截止日期，以及已完成任务的记录。
- **课程**：在学什么。当前课程及其大纲、该学科的其他课程，以及与之相关的决定：换课程、重新诊断和重置知识档案。

知识点页面和任务属于其课程的学科，并显示该学科的标签。

**学科切换器**从页头的学科标签打开。它列出学习者的学科，每个学科附带当前课程和今天的 XP 对比目标，并提供尚未开始的学科，点进去是该学科的课程目录。

## 4. 布局

**网页。**

| 路径 | 页面 |
| :--- | :--- |
| `/` | 未登录是落地页；已登录是当前学科的学习页 |
| `/{subject}` | 学习 |
| `/{subject}/progress` | 进度 |
| `/{subject}/history` | 已完成任务的记录 |
| `/{subject}/course` | 课程 |
| `/{subject}/topics/{topic}` | 重读一个知识点 |
| `/session/{id}` | 一个任务 |
| `/courses` | 公开的课程目录，每个学科一个标签页 |
| `/courses/{course}` | 课程的公开页面 |
| `/settings` | 账户 |
| `/guardian`、`/guardian/{learner}` | 监护人的学习者，以及其中一位 |
| `/league` | 联赛 |

页头包括标志、带切换器的学科标签、学科的三个页面，右侧是联赛和账户菜单。在学科之外（课程目录、账户、联赛），学科标签换成页面名称。

**应用。** 在桌面上，侧边栏以学科标签开头，点击打开切换器，接着是学科的三个页面；账户从侧边栏底部打开。在手机上，顶栏标题是学科标签，标签栏是学习、进度、课程和我，「我」里是账户。

**课程目录。** 课程目录一次显示一个学科，由顶部的标签页选择；其中的书架（年级、考试、大学）是该学科自己的。课程页用学科标签标明所属学科。

## 5. 监督

学习者的**监督人**替他们做决定：

- 成年人监督自己；
- 未成年人由其监护人监督，任何一位监护人都可以决定；
- 没有监护人的青少年在有监护人关注之前监督自己。儿童总有监护人，账户由监护人创建。

**学科的决定：**

| 决定 | 位置 | 何时有帮助 |
| :--- | :--- | :--- |
| 换课程 | 课程 | 课程太容易或太难，或有了新目标（某个年级、某场考试）。进度会保留；确认时显示新课程中哪些知识点已经掌握，以及预计完成时间。 |
| 重新诊断 | 课程 | 中断超过十周之后，或在 Great Academy 之外学过之后。诊断判定的知识点会重新提问；课时学会的知识点保留，由复习来纠正。执行前会再问一次。 |
| 重置知识档案 | 课程 | 记录不可信时：做题借助了外部帮助或工具，或档案与实际掌握相差很远。推断从重置时重新开始；记录和 XP 保留。执行前会再问一次。 |
| 每周目标 | 进度 | 该学科一周中每天要获得的 XP。 |
| 截止日期 | 进度 | 课程应在何时学完；预计完成会说明当前速度是否足够，以及每天需要多少 XP。 |

监护人在学习者的页面上做这些决定。该页面有同样的学科切换器，以只读方式显示学习者的学习、进度和课程页面，决定的操作可用。不是自己监督人的学习者能看到每个决定的当前值和「由你的监护人决定」，没有操作按钮。

## 6. 监护人

监护人的列表显示每位学习者及其各学科的标签，以及每个学科今天和本周的 XP 对比目标。学习者的页面打开最近学习过的学科。
