# 数论

> 这是 Great Academy 自己的课程大纲，不来自参考目录。依据：本科第一门课程的标准内容，如 Niven、Zuckerman 和 Montgomery 或 Hardy 和 Wright 的教材。[English](number-theory.md) · [数学课程目录](../math-curriculum.zh-CN.md)。

- **阶段：** 大学
- **先修：** 证明方法
- **规模：** 5 个单元 · 10 个模块 · 78 个知识点

## 说明

因数和质数，通过费马定理和欧拉定理研究模 n 的幂，原根和离散对数，二次剩余和互反律，算术函数和质数的大小，经典的整数方程，以及分解和公钥密码学。

## 学习成果

- 运用整除、欧几里得算法和唯一分解。
- 解同余式，并运用费马、欧拉、威尔逊定理和中国剩余定理。
- 处理阶、原根、二次剩余和二次互反律。
- 运用算术函数、莫比乌斯反演和狄利克雷级数。
- 用无穷递降、二次型、连分数和佩尔方程求解丢番图方程。
- 把数论用于素性检验、分解和公钥密码。
- 初步认识 p 进数和模素数椭圆曲线的群。

## 范围取舍

- 素数定理和哈塞定理只陈述而不推导，它们的证明需要超出本课程的分析工具。
