# 实分析

> 这是 Great Academy 自己的课程大纲，不来自参考目录。依据：第一门课程的标准内容，如 Abbott 的教材或 Rudin《数学分析原理》的前十一章。[English](real-analysis.md) · [数学课程目录](../math-curriculum.zh-CN.md)。

- **阶段：** 大学
- **先修：** 微积分 II 和证明方法
- **规模：** 5 个单元 · 8 个模块 · 82 个知识点

## 说明

微积分的严格基础：完备性，数列和级数，用 ε 和 δ 研究极限和连续，紧性和连通性，黎曼积分和斯蒂尔杰斯积分，测度初步，以及一致收敛及其应用。

## 学习成果

- 由定义证明数列和级数的极限，并运用实数的完备性。
- 处理实数轴和度量空间中的开集、闭集、紧集和连通集。
- 证明连续、导数和黎曼积分的主要定理。
- 用一致收敛判断极限何时可以交换。
- 运用逼近定理、等度连续、压缩映射原理和傅里叶级数。
- 理解勒贝格测度和积分，以及单调收敛定理和控制收敛定理。

## 范围取舍

- 反函数定理在多元微积分中讲授，这里不再重复。L^p 空间属于第二门课程。
