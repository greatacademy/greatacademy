# 1st Grade Math

> This is Great Academy's own outline, not from the reference catalog. Basis: the Common Core State Standards for this grade. [简体中文](1st-grade-math.zh-CN.md) · [math curriculum catalog](../math-curriculum.md).

- **Level:** Elementary School
- **Prerequisite(s):** Counting and early number sense
- **Size:** 13 units · 21 modules · 61 topics

## Description

Counting to 120, tens and ones, adding and subtracting within 20, word problems, adding tens, length, time, first graphs and shapes.

## Outcomes

- Add and subtract within 20, using strategies and the relation between the operations (1.OA).
- Count, read and write numbers to 120, and use tens and ones to compare and to add within 100 (1.NBT).
- Measure lengths with units, tell time to the half hour, and organize data in up to three categories (1.MD).
- Tell shapes apart by defining attributes, compose shapes, and cut them into halves and fourths (1.G).

## Scope decisions

- Coins go beyond the standards for this grade and prepare for 2nd Grade.
