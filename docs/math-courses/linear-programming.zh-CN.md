# 线性规划

> 这是 Great Academy 自己的课程大纲，不来自参考目录。依据：第一门课程的标准内容，如 Chvátal、Vanderbei 或 Bertsimas 和 Tsitsiklis 的教材。[English](linear-programming.md) · [数学课程目录](../math-curriculum.zh-CN.md)。

- **阶段：** 大学
- **先修：** 线性代数
- **规模：** 4 个单元 · 8 个模块 · 52 个知识点

## 说明

线性约束下的优化：建立规划，图解法和单纯形法，对偶和灵敏度，建模技巧，运输、指派和流问题，整数规划和分支定界，大规模规划，以及矩阵博弈。

## 学习成果

- 把决策问题写成线性规划，并理解它们的几何。
- 执行单纯形法，包括初始阶段、有界变量、退化和修正形式。
- 陈述并运用对偶、互补松弛和灵敏度分析。
- 求解运输、指派、流和最短路问题。
- 用分支定界和割平面求解整数规划，并求解矩阵博弈。
- 解释多项式时间方法：椭球法和障碍法。

## 范围取舍

- 原始-对偶内点法的实现和随机规划属于第二门课程。
