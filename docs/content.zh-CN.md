# 内容

> [English](content.md) | 简体中文

本文规定 Great Academy 的内容模型，以及内容如何编写、校验和提供给学习者。内容模型位于 `libs/content`，不了解任何具体学科；一个学科以 `SubjectDef` 的形式提供它的知识点、课程和答案判定器。

教学法背景见 [The Math Academy Way](the-math-academy-way.zh-CN.md)；引擎如何使用知识图谱见[学习引擎](learning-engine.zh-CN.md)。

---

## 1. 概念

| 概念 | 类型 | 含义 |
| :--- | :--- | :--- |
| 学科 | `SubjectDef` | 例如数学：一张知识图谱、它的课程、它的判定器 |
| 知识点（topic） | `TopicDef` | 一个可教授的概念；知识图谱中的一个节点，也是一节课 |
| 知识步骤（knowledge point） | `KnowledgePointDef` | 知识点中的一步：讲解、例题、练习题 |
| 先修边 | `TopicDef.prerequisites` | 必须先学会这些知识点 |
| 包含边 | `EncompassingDef` | 练习该知识点会隐式地练习一个更简单的知识点的一部分（`weight`） |
| 关键先修 | `KnowledgePointDef.keyPrerequisites` | 这一步最直接依赖的先前知识点，用于补救 |
| 课程 | `CourseDef` | 按单元和模块排列的一组有序知识点，以及掌握下限 |
| 题目 | `Problem` | 一次生成的实例：题面、答案规格、解答、标准答案和错误答案 |
| 判定器 | `Checker` | 根据题目的期望数据判断作答 |

## 2. 文字与语言

每段用户可见的字符串都是 `Text`：每种语言一段 Markdown。语言为 `en` 和 `zh-CN`；数学用 TeX 写在 `$…$`（行内）或 `$$…$$`（独立显示）之间。

```ts
import { t, same } from "@ga/content";

t("Add the numbers.", "把这两个数相加。");
same("$3 + 4$");   // 各语言相同
```

编译器和生成器抽样都会拒绝在任一语言中为空的文字。

## 3. 知识点

```ts
const addingIntegers: TopicDef = {
  id: "adding-integers",
  title: t("Adding Integers", "整数加法"),
  summary: t("Add positive and negative integers.", "正负整数相加。"),
  prerequisites: ["integers-on-the-number-line"],
  encompasses: [{ topic: "integers-on-the-number-line", weight: 0.5 }],
  xp: 12,
  knowledgePoints: [sameSign, differentSigns],
  standards: ["CCSS.7.NS.A.1"],
};
```

规则：

- **Id** 使用 kebab case，在学科内唯一，一经发布不得更改，因为学习者状态引用它们。knowledge point 的 id 在所属知识点内唯一。
- **粒度。** 知识点是值得单独上一节课的最小概念：两到五个 knowledge point，`xp`（认真学习者预计花费的分钟数）通常在 8 到 25 之间。
- **先修**只列直接先修。被另一个先修蕴含的先修是多余的，会产生警告。
- **包含边**指向祖先（直接或间接先修）。不是祖先的等价知识点只有标记 `nonAncestor: true` 才能被包含。`weight` 在 (0, 1] 内：1 表示完整练习了那个更简单的知识点，0.5 表示练习了一半。
- **只练习的知识点。** `practiceOnly: true` 标记不教新内容的知识点，例如考试题型知识点：课程从练习开始，讲解和例题只在课程失败之后出现。
- **诊断 knowledge point。** 诊断对每个知识点只出一道题，取自 `diagnostic` 指定的 knowledge point，默认取最后一个，因为它最完整。

## 4. Knowledge Point 与生成器

knowledge point 是课程流程中的一步：学习者阅读 `explanation`，研究一道例题，然后回答同一生成器产生的练习题，直到通过（见[学习引擎](learning-engine.zh-CN.md)）。

```ts
const sameSign: KnowledgePointDef = {
  id: "same-sign",
  title: t("Same signs", "同号相加"),
  explanation: t("To add two integers with the same sign, …", "两个同号整数相加，…"),
  keyPrerequisites: ["integers-on-the-number-line"],
  generate(rng) {
    const s = rng.sign();
    const a = s * rng.int(2, 30);
    const b = s * rng.int(2, 30);
    return {
      prompt: t(`Evaluate $${a} + (${b})$.`, `计算 $${a} + (${b})$。`),
      answer: { checker: "number", expected: a + b, input: { kind: "math" } },
      solution: t(…, …),
      canonical: String(a + b),
      wrong: [String(Math.abs(a) + Math.abs(b) * -s), String(a - b)],
    };
  },
};
```

生成器是从带种子的 `Rng` 到 `Problem` 的函数：

- **确定性。** 相同的种子总是产生相同的题目。题目以引用 `{ topic, kp, seed }` 的形式存储，需要时在服务器上重新生成。因此题目本身无需存储，答案在学习者作答之前也无需离开服务器。
- **不使用外部随机数或时间。** 只用传入的 `Rng`（`int`、`nonZero`、`sign`、`bool`、`pick`、`shuffle`、`sample`）。`createRng` 是经 splitmix32 播种的 sfc32；`hashSeed` 把字符串转为种子。
- **标准答案。** `canonical` 是判定器必须接受的作答，写成学习者会输入的样子。答错后也会展示它。
- **错误答案。** `wrong` 列出典型错误产生的作答（符号错误、该减却加、要求化简时给出未化简形式），判定器必须拒绝每一个。它们记录了这一步针对的误解，也防止判定器过于宽松。
- **多样性。** 生成器必须产生足够多不同的题目，使同一学习者的练习和复习很少重复。
- **不泄露答案。** 题面绝不包含答案；铺垫应放在讲解、例题和额外的 knowledge point 中。
- **必定终止。** 凡是“重试直到满足条件”的循环，都必须对参数的每一种取值成功。要检查极端值：除数为 9、被除数为两位数时，不存在所要求形式的商，若生成器抽到它并不断重试，抽样就会卡死。
- **每个值都有定义。** 错误答案与正确答案由同一组参数算出，因此每一个都要防护：可能为零的分母、定义域之外某点的函数值、越过列表末尾的下标。
- **模板字符串。** 插入 `${…}` 的文字必须写成模板字符串；写在普通引号字符串里，它会原样显示给学习者。
- **图形。** 题目可以带一个题面引用的 `figure`，knowledge point 可以带一个随讲解展示的 `figure`。`Figure` 是 `{ svg, alt }`：带 `viewBox` 的自包含 SVG 图，用 `currentColor` 绘制，从而在浅色和深色主题下都跟随客户端的文字颜色；客户端可用强调色绘制的部分带 class `accent`。图中的文字与语言无关（数字、字母、单位）；`alt` 用每种语言描述图形，供屏幕阅读器使用。客户端直接内嵌 SVG，所以只能使用绘图元素（`svg`、`g`、`line`、`polyline`、`polygon`、`path`、`circle`、`ellipse`、`rect`、`text`、`tspan`、`title`、`defs`、`marker`），不能有事件处理器、`style` 属性、链接或 `url()`。

## 5. 答案与判定器

`AnswerSpec` 告诉服务器如何判定，告诉客户端显示什么：

| `input.kind` | 客户端显示 | 作答内容 |
| :--- | :--- | :--- |
| `choice` | 按顺序显示 `options` | 所选选项的下标 |
| `math` | 数学输入框，可带 `prefix` 和 `suffix`（例如 `x =` 或 `\text{cm}`） | 学习者输入的 LaTeX |
| `text` | 普通文本框 | 文本 |

`checker` 指定一个已注册的判定器，`expected` 是该判定器的数据。核心注册两个判定器，学科注册自己的判定器（数学有数、分数、表达式、方程等）。

| 判定器 | `expected` | 接受 |
| :--- | :--- | :--- |
| `choice` | 正确选项的下标 | 正好是该下标 |
| `text` | 可接受字符串的数组 | 其中任意一个，忽略大小写、Unicode 全半角和空白 |

判定器返回 `Verdict`：`correct`，以及在拒绝需要解释时可选的 `feedback`（例如"请化简分数"）。`CheckerRegistry`：

- 拒绝 id 重复的判定器；
- 拒绝超过 2,000 个字符的作答；
- 判定器抛出异常时视为答错。

判定器对**值**必须严格，对**形式**必须明确：当一个知识点教的是化简时，`expected` 写明要求化简形式，判定器拒绝相等但未化简的答案并给出反馈。

## 6. 课程

```ts
const prealgebra: CourseDef = {
  id: "prealgebra",
  title: t("Prealgebra", "代数预备"),
  description: t(…, …),
  masteryFloor: ["counting"],
  units: [
    { title: t("Integers", "整数"), modules: [{ title: t("Adding and Subtracting", "加法与减法"), topics: ["adding-integers", …] }] },
  ],
};
```

- 课程按教学顺序列出知识点，单元和模块只用于展示分组。
- 每个知识点只出现一次，并且排在它在本课程中的所有先修之后。
- **掌握下限。** 假定该课程的每个学习者都已掌握的知识点。它们及其祖先永远不会被本课程讲授或复习。下限中的知识点不能出现在课程中。
- **基础**（计算得出）。课程知识点的祖先中，既不在课程中、也不在下限之下的那些。诊断会测定学习者对它们的掌握情况，缺少这些基础的学习者会先学习它们。

## 7. 编译器

`compileSubject(def)` 校验 `SubjectDef` 并构建引擎使用的索引。任何错误都会抛出 `CompileError`，列出全部问题，每个问题带有路径，例如 `topic adding-integers › kp same-sign`；警告通过 `CompiledSubject.warnings` 返回。

| 检查 | 级别 |
| :--- | :--- |
| Id 为 kebab case 且唯一；文字在每种语言中非空；`xp > 0`；至少一个 knowledge point；诊断 knowledge point 存在 | 错误 |
| 先修存在、不是自身、不重复、不成环 | 错误 |
| 先修被另一个先修蕴含 | 警告 |
| 被包含的知识点存在、除非标记 `nonAncestor` 否则必须是祖先、权重在 (0, 1] 内、不成环 | 错误 |
| 关键先修是所属知识点的祖先 | 错误 |
| Knowledge point 的图形合乎规定（§4），且 alt 文字在每种语言中非空 | 错误 |
| 课程中的知识点存在、不重复、排在本课程内先修之后；下限中的知识点不在课程中 | 错误 |

编译后的图谱提供：

- `order`：知识点的拓扑序，在定义顺序上保持稳定；
- `dependents`：先修边的反向；
- `encompassedBy`：包含边的反向，带权重；
- `ancestors`：每个知识点的传递先修，近者在前。

## 8. 生成器抽样

`sampleGenerators(subject, { samples, minDistinct })` 用许多种子（默认 200 个）运行每个生成器。生成器出现以下情况时报告错误：

- 抛出异常，或不确定；
- 生成的文字在某种语言中为空，或含有 `NaN`、`undefined`、`Infinity`、`[object Object]`；
- 带有不合规定的图形（§4）；
- 指定了未知判定器；
- 选择题：选项少于两个、选项重复，或期望下标越界；
- 标准答案被判定器拒绝，或某个错误答案被判定器接受；
- 给出选项 `textIssue(text, locale)` 时：题面、解答或选项被该函数报告有问题，学科可借此执行自己的书写规则；
- 给出选项 `maxPositionShare` 时：选择题的正确选项落在同一位置的样本超过该比例。

不同题面少于 `minDistinct` 个时发出警告；图形或选项集合不同的题面算作不同。每个内容包都在测试中运行 `compileSubject` 和 `sampleGenerators`，因此运行时会拒绝的内容无法合入。选项 `shard: { index, count }` 只抽样从第 `index` 个起每隔 `count` 个的主题，内容包可以借此把抽样分到 Vitest 并行运行的多个测试文件中；`content/math` 分成四份，并传入自己的 `textIssue`（`$` 成对、数学模式外无 LaTeX、无连写正负号、中文中无成串英文）和 0.8 的 `maxPositionShare`。

## 9. 提供题目

`generateProblem(subject, ref)` 根据 `ProblemRef`（`{ topic, kp, seed }`，`kp` 是 knowledge point 的下标）重新生成题目。服务器只向客户端发送 `viewOf(problem)`：题面、图形和输入规格。答案、标准答案和解答只在学习者作答之后才公开，作答在服务器上判定。

## 10. 数学

`libs/subject-math` 在精确计算的基础上实现数学判定器：解析数学输入框产生的 LaTeX 子集（数、变量、`+ - \cdot \times \div /`、省略乘号、`\frac`、`^`、`\sqrt`、括号、`= < > \le \ge`），基于 `bigint` 的有理数运算（`Q`），以及多项式标准形式。判定答案的过程不涉及浮点数。解析器保留作答的书写形式（括号、`\frac` 与 `/`、小数），因此判定器既能判断值，也能判断形式。

| 判定器 | `expected` | 接受 |
| :--- | :--- | :--- |
| `number` | `{ value, form?, var?, percent?, unit? }`：`value` 是有理数，例如 `"-3"`、`"3/4"`、`"2.5"` | 等于 `value` 的单个数。`form` 为 `"number"`（默认）：整数、小数、最简分数或带分数；`"integer"`；`"fraction"`（不接受小数）；`"decimal"`；`"mixed"`（整数、带分数或真分数）。`3+4` 这样的算式会被拒绝并给出反馈。有 `var` 时也接受 `x = 3` 和 `3 = x`。有 `percent` 时输入框后显示 `%`，学习者自己输入的 `%` 会被忽略；`unit`（`"°"` 或 `"cm"`、`"cm^2"` 等单位）同理 |
| `expression` | `{ expr, form?, positive? }`：`expr` 是 LaTeX | 与 `expr` 等价的式子：多项式精确比较；其他式子在若干有理点上精确比较，根式以 c·ⁿ√r 之和的形式精确保留（因此 3∛(2x²) 等于 ∛(54x²)）；值超出这种形式的点，如负数的分数次幂，会被跳过。式子中可以有根式 `\sqrt[n]{…}`、绝对值 `|…|`、分数指数（`x^{\frac{3}{4}}` 即 ⁴√(x³)，`200(0.5)^{\frac{t}{3}}`）和含变量的指数（`x^{a+b}` 等于 `x^{a}x^{b}`）。`positive: true` 时只代入正数，使 √(x²) 等于 x。`form: "simplified"` 时，作答还必须是最简形式的单项式之和：没有同类项、没有括号、没有系数 1、没有连续的符号，单项式可以有单项式分母，但分母与分子没有公共的变量或数因数，如 $\frac{8x^{6}}{27y^{3}}$；`form: "radical"` 时必须是最简根式：每项至多一个根式，n 次根号内没有完全 n 次方因数（数、指数不小于 n 的变量、重复 n 次的多项式因式，因此 $\sqrt{x^2-6x+9}$ 不是最简），根号内没有分数，分母中没有根号，绝对值符号内没有可提出的数因数或分数（写 6|x|，不写 |-6x|），没有同类项，其中整系数的和可以除以一个与所有系数没有公因数的数，如 $\frac{3+\sqrt{5}}{2}$；`form: "lowest"` 时必须是多项式，或两个多项式之比的最简分式，分子分母各自写成展开式或化简后因式的乘积（至多一个数且写在最前，不同变量的幂，以及括号中的和，因此 $2 \cdot 3x^{5}$ 和 $(2x^{2})^{3}$ 都不符合），且没有公因式（多元时只检查公共的数与单项式）；`form: "vertex"` 时必须是顶点式 $a(x-h)^{2}+k$，只含一个完全平方的二项式，a、h、k 是最简形式的数，a 为 1 时省略，k 为 0 时省略，h 为 0 时写成 $ax^{2}+k$：`2(x-3)^{2}+1`、`-(x+1)^{2}-4`、`(x-5)^{2}`；其他等价形式会被拒绝并给出反馈 |
| `function` | `{ expr, var?, constant?, positive? }`：`expr` 是 LaTeX | 作为函数与 `expr` 相等的式子，用浮点数在十二个固定、不规则、有正有负的点上比较（`positive: true` 时只用正的点）：每个点上两边要么都没有定义，要么在约八位有效数字内相等，且至少在四个点上相等。式子中可以有 `expression` 能识别的一切，以及 `\sin`、`\cos`、`\tan`、`\sec`、`\csc`、`\cot`、`\arcsin`、`\arccos`、`\arctan`（也可写 `\sin^{-1}`）、`\sinh`、`\cosh`、`\tanh`、`\exp`、`\ln`、`\log`（以 10 为底）和 `\log_{b}`，以及常数 e 和 π；`\sin^{2}x` 即 $(\sin x)^{2}$，不带括号的自变量延续到数与字母的乘积为止，因此 `\sin 2x` 即 $\sin(2x)$。不带反斜杠输入的函数名也能识别。指定 `constant`（如 `"C"`）时，作答是原函数：它与 `expr` 只能相差一个关于变量 `var`（默认 x）的常数，并且必须含有积分常数，否则会被拒绝并给出反馈 |
| `inequality` | `{ var, op, value }`：`op` 为 `<`、`<=`、`>` 或 `>=` | `x < 3` 或等价的 `3 > x`，其中的数按 `number` 的规则书写 |
| `factorization` | `{ value }`：不小于 2 的整数 | 乘积等于 `value` 的质数及质数幂之积，顺序不限：`2^{3} \cdot 3` 或 `2 \cdot 2 \cdot 2 \cdot 3`。含合数因数的乘积，或 `value` 为合数时直接写 `value`，会被拒绝并给出反馈 |
| `scientific` | `{ value }`：有理数 | 用科学记数法表示的 `value`：`a \times 10^{n}`（或 `\cdot`），其中 `1 ≤ \|a\| < 10` 写成整数或小数，或单独的 `10^{n}`。其他形式的相同值会被拒绝并给出反馈 |
| `radical` | `{ coef, radicand }`：有理数与不小于 1 的无平方因数整数 | 最简根式形式的 `coef·√radicand`：`6\sqrt{2}`、`-\sqrt{5}`、`\frac{2\sqrt{3}}{3}` 或 `\frac{2}{3}\sqrt{3}`；radicand 为 1 时是有理数。值相同但根号内含平方因数、分母含根式或分数未约分的答案会被拒绝并给出反馈 |
| `solutions` | `{ var, values }`：用 LaTeX 写出的各个解，可以是有理数，也可以是 `\frac{3+\sqrt{5}}{2}` 这样的数；无解时为空 | 解集：各个解顺序不限，用逗号、分号或“或”分隔，每个解单独写出或写成 `x = …`，可以用 `\pm`（`x = \pm 3`、`\frac{3 \pm \sqrt{5}}{2}`）；无解时写 `\varnothing`、`\emptyset` 或“无解”。重复的解只算一次。每个数都必须是最简形式，否则会被拒绝并给出反馈 |
| `interval` | `{ set, form?, var? }`：`set` 用区间记号书写；`form` 为 `"interval"` 或 `"inequality"` | 与 `set` 相等的实数集合。`form` 为 `"interval"` 时用区间记号：`(-2, 5]`、`(-\infty, 1) \cup [3, \infty)`、`\mathbb{R}`、`\varnothing`，单个点写作 `\{3\}`；为 `"inequality"` 时用关于 `var` 的不等式：`-2 < x \le 5`、`x < 1 \text{ or } x \ge 3`、`x > 0 \text{ and } x \le 4`、`x = 3`；不指定 `form` 时两种都可以。两种形式下空集都可以写作“无解”。用另一种形式书写的答案会被拒绝并给出反馈；端点必须是最简形式的数 |
| `point` | `{ values, vars? }`：有理数 | 与 `values` 相等的有序数对或数组：`(3, -2)`；给出 `vars` 时也可以写成 `x = 3, y = -2`，顺序不限；每个数的写法与 `number` 相同 |
| `equation` | `{ eq, form?, vars? }`：用 LaTeX 写出的多项式方程；`form` 为 `"slope-intercept"`、`"standard"` 或 `"point-slope"` | 两边之差是 `eq` 两边之差的非零倍数的方程：对 `y = 2x + 3`，`4x - 2y + 6 = 0` 也正确。`form` 要求关于 `vars`（默认 `x` 和 `y`）的直线方程形式：右边已化简的 `y = mx + b`；`A`、`B`、`C` 为没有公因数的整数且 `A > 0` 的 `Ax + By = C`；或 `y - k = m(x - h)`。等价但形式不对的方程会被拒绝并给出反馈 |

**读图题。** `content/math/src/topics/figure-reading.ts` 中的 `figureReadingPoints` 按主题 id 为大学课程的主题追加知识点，排在主题自身的知识点之后：把向量场、等值线、二次曲面或极坐标曲线与公式对应，以及从图上读出积分限、矩阵、投影或概率。`content/math/src/index.ts` 中处理每个主题的步骤负责追加。`libs/subject-math` 中的 `plane` 负责画箭头、等值线、折线和阴影多边形。

**主题跳过的技能。** `content/math/src/topics/deeper-*.ts` 中的 `deeper…Points` 映射分别对应抽象代数、微积分 I、微积分 II、微分方程、离散数学、线性代数、证明方法、多元微积分和概率统计，按主题 id 为这些课程的主题追加知识点，排在主题自身的知识点之后、读图题之前。每个知识点都是主题自身没有涉及的技能，例如由逆矩阵解方程组、拉格朗日乘数或全方差公式，而不是已有技能的另一种版本。主题已有的 id 不变，所以学习者状态仍然有效。

**文本规整。** 生成器按一般情况编写，随机值取 1 时会得到"$1x$"或"$1$ hours"。`polishTopic` 包装学科的每个生成器：在学习者读到的内容中（不含答案）去掉系数 1 和等式链中重复的值；在英文中让名词与数量 1 保持一致，并在 8、11 这类数字前写"an"。模板按一般情况编写，这些交给它处理；其他书写规则由 `mathTextIssue` 通过抽样检查（§8）。

**推断的包含边。** 没有自己包含边的知识点从 `content/math/src/encompassings.ts` 取得，权重来自该知识点用到每个直接先修多少词汇，上限为 0.5，因为它们没有逐条审核。一个知识点同时有两者时测试会失败，所以在知识点上写包含边时要删除这里的条目。

`content/math` 用 `numberProblem`、`expressionProblem`、`inequalityProblem`、`factorizationProblem`、`scientificProblem`、`radicalProblem`、`solutionsProblem`、`intervalProblem`、`pointProblem`、`equationProblem`、`factoredProblem`、`functionProblem`（答案以 $+ C$ 结尾时加 `antiderivative`）和 `choiceProblem` 构建题目。它们填写答案规格、标准答案和输入方式（`expressionProblem` 可以指定要求的形式、`positive`，以及显示在输入框前的 `prefix`，如 `y =`），并去掉在某个种子下恰好等于正确答案的错误答案。题面和解答中的 LaTeX 用 `num`、`paren`、`poly`、`linear` 书写，它们不会产生 `+ -`、`1x` 或 `-1x`；小数用 `dec`、科学记数法用 `sci`、最简根式用 `radical`、形如 $a + b\sqrt{m}$ 的数用 `surdLatex` 书写（`surdValue` 精确计算这类数）。实数集合用 `union`、`intersect` 和 `parseIntervals` 构造，用 `intervalLatex` 和 `inequalityLatexOf` 书写。图形用 `dotPlot` 和 `boxPlot` 在 `Axis` 上绘制；几何图形用 `sketch` 由图形自身坐标中的标记绘制：线段、多边形、带空洞的阴影区域、角弧、直角记号、标签、边长、表示等长的短线和表示平行的箭头。函数图像用 `plane` 在坐标平面的一个窗口里绘制：网格、带刻度数字的坐标轴、曲线 $y = f(x)$、直线、线段、圆、实心点与空心点、标签，以及若干半平面同时成立（还可限定在圆内或圆外）的阴影区域，全部裁剪到窗口之内。`sketch` 把每个图形缩放到大致相同的尺寸，使标签大小一致，并让 viewBox 覆盖所画的全部内容，包括标签。要求小数或带分数的答案，标准答案也写成那种形式。

编写数学生成器时的常见陷阱：

- 数值类错误答案只能是整数或 `Q` 值：`wrong` 在 `bigint` 上精确判定，用浮点数算出的分数（如 `n / 10`）会抛出异常。这类值用 `Q.of(a, b)` 或 LaTeX 字符串构造。
- `expression` 判定器在约 ±15 以内的固定有理数采样点上比较表达式，且至少需要三个两边都有定义的点。只在远离零处才有定义的答案（如 $\sqrt{x - 20}$）无法判定；平移量和定义域要保持在这个范围内。含三角、指数或对数函数的答案用 `function` 判定器，它在约 ±3.2 以内的点上比较；这类答案的定义域也要落在这个范围内。
- 避免答案落在舍入边界上：题目要求四舍五入时，所选数值的精确结果不要在舍入误差范围内接近 0.5。
- 知识点文件中的每个知识点都要放进该文件导出、并由 `src/index.ts` 展开的列表；漏掉的知识点会悄无声息地缺失，依赖它的知识点则无法编译。

**四年级数学**（`4th-grade-math`，七个单元共 931 个知识点）是第一门小学课程。它先建立数位概念、多位数加减法，以及基于面积模型和数位策略的乘除法；再引入分数、带分数、等值分数、同分母分数加减法、整数乘分数和十进分数，其中多数先借助长条图和数轴图来学习；最后是单位与换算、线图，以及直线、射线与角的几何（配有量角器图）。表达式与规律这一单元用到乘除法，因此排在乘法和除法之后。

**五年级数学**（`5th-grade-math`，八个单元共 134 个知识点）紧随其后。它从整数表达式和负数初步开始，接着是多位数乘除法；然后是异分母分数和带分数的加减法、分数乘除法；把数位扩展到小数，并学习小数的四则运算（包括除以小数）；通过 10 的幂引入指数；最后是化成较大的单位、分数线图、坐标平面的第一象限、数的规律、长方体的体积（配有单位立方体图）以及多边形和四边形的分类。

**六年级数学**（`6th-grade-math`，八个单元、28 个模块共 157 个知识点）按完整的共同核心大纲编写。它从比、比例表与比的图像、线段图、单位率、百分比和单位换算开始；接着是多位数除法、借助模型和倒数的分数除法，以及小数运算；然后引入有理数、绝对值、四个象限的坐标平面和指数；再写出、求值、化简和因式分解一次式，解一步方程并用它建模，在数轴上表示不等式，并用表格和图像分析二元方程（`grade-6-ratios.ts`、`grade-6-number-system.ts`、`grade-6-expressions.ts`、`grade-6-equations.ts`）。几何部分求边长为分数或小数的长方形、三角形和平行四边形的面积，用分割法求多边形面积，判断对称轴，用单位分数棱长的小正方体填充长方体，并在坐标平面中度量多边形（`grade-6-geometry.ts`，配有几何草图、长方体和坐标图）；统计部分用集中趋势和离散程度的量、离群值、频数表和点图概括数据（`grade-6-statistics.ts`）。

**七年级数学**（`7th-grade-math`，五个单元、27 个模块共 170 个知识点）完整遵循共同核心标准大纲。它由分数与带分数之比求单价与单位率，在表格、图象和文字描述中识别比例关系，并应用百分比变化、商业与金融中的百分数以及单利；进行有理数的加减乘除，计算底数为有理数的乘方；化简与分解一次式，解一步与多步一次方程、二元方程、代入法解方程组与一次不等式，用它们建模，并化简分式；学习线段、角的关系、三角形与四边形、组合图形的面积与周长、比例图、圆，以及棱柱的体积、表面积与截面；最后学习抽样与调查估计、频数表与直方图、按集中趋势、离散程度和重叠程度比较数据集、概率模型，以及复合事件的样本空间、试验概率与理论概率和模拟。**八年级数学**（`8th-grade-math`，九个单元、27 个模块共 134 个知识点）完整遵循共同核心标准大纲。它区分有理数与无理数并估算无理数；学习整数指数、指数运算法则、科学记数法，以及公式和变化率中的单位；求平方根与立方根，化简根式并进行根式运算，用平方根和立方根解方程；学习整除与质数；解一元一次方程，求直线的斜率与方程，分析一次方程并用它建模，用代入法和消元法解方程组；认识函数及其表示与性质，用变化率和初始值建立一次函数模型；学习角与平行线、三角形与多边形的角、刚体变换与全等、位似与相似；证明并在平面与空间中应用勾股定理及其逆定理，求距离以及圆柱、圆锥与球的体积；最后学习散点图、关联模式、趋势线及其拟合、预测，以及双向表中的相对频率与关联。

**SAT 数学基础**（`sat-math-fundamentals`，十七个单元共 660 个知识点）与 **SAT 数学冲刺**（`sat-math-prep`，四个单元共 284 个知识点）为数字 SAT 考试提供专项目标准备。SAT 数学基础构建涵盖算术、一次方程与不等式、直线与坐标系、几何与立体测算、直角三角形三角学、函数与图象变换、绝对值、二次方程与韦达定理、多项式与余数定理、指数模型、分式与根式方程、比与百分比、以及统计与概率的完整数学基础，并针对性融入多项式待定系数、二次抛物线顶点参数与误差范围解读等关键“缺失的中阶”（missing middle）高频考法。SAT 数学冲刺按 College Board 官方四大考试板块组织：代数（一次方程、方程组、不等式与图象）、进阶数学（多项式、二次函数、非线性方程与指数模型）、几何与三角学（角、三角形、圆、坐标几何与直角三角形三角学）以及问题解决与数据分析（比、百分比、单位换算、散点图与概率）。其中 252 个是考试题型知识点（`sat-exam-*`），与真实考试一样，约四分之三是选择题，四分之一是学生填答题；其余 32 个是普通知识点。

**ACT 数学基础**（`act-math-fundamentals`，七个单元共 928 个知识点）与 **ACT 数学冲刺**（`act-math-prep`，六个单元共 348 个知识点）为 ACT 统一数学考试提供专项目标准备。ACT 数学基础全面覆盖考纲要求的数学概念与题型：数与数量（质数、因数、分数运算、根式与指数幂、科学记数法、条件命题与形式逻辑初步）、基本技能整合（比、单位率、比例方程、百分比与多步单位换算）、代数（一元与多元一次方程、方程组、不等式、绝对值方程、多项式因式分解、二次方程、分式与根式方程以及非线性方程组）、函数（定义域、值域、平移变换、二次与指数函数、对数性质与方程、数列与级数）、几何与三角学（点线角、多边形、直角三角形、全等与相似、面积与周长、解析几何、圆与扇形、立体几何、正余弦定理与恒等式、圆锥曲线、平面向量、复平面与矩阵）、统计与概率（集中趋势、离散程度、统计图表、加法法则与互补独立事件、排列组合与随机抽样）以及数学建模（回归模型选择）。ACT 数学冲刺按官方六大报告类别组织，包括矩阵、平面向量、三角学、对数与圆锥曲线等预备微积分层次的内容。其中 346 个是考试题型知识点（`act-exam-*`），题目全部是四选一；其余 2 个是普通知识点。其中 124 个考试知识点与 SAT 数学冲刺的某个知识点讲同样的数学，它们共用先修和提示，但各有自己的题目，因此同时学两门课的学生不会看到相同的题。大纲在两个模块中都列了“解指数方程”；一门课只能列一次同一知识点，所以函数模块改用“求指数函数的输入值”。

考试题型知识点由 `content/math/src/exam.ts` 根据每个大纲标题的一份规格生成。其 id 为 `<exam>-exam-<title>`，含两个小知识点 `exam-question` 和 `harder-exam-question`，题目按考试风格编写。它只练习，因为数学内容由基础课程的知识点讲授，它们被列为先修并被其涵盖；讲解是一段简短的提示，给课程失败的学习者看。

涉及图形的题目会画出图形（`content/math/src/exam-figures.ts`），标出已知量，并在所求之处标 "?"；若画出来会泄露答案，则不画。数值选项按从小到大排列，与真实考试一致。为了不让“选最小的”成为捷径，答案的位置随机抽取；干扰项偏多的一侧，其干扰项关于答案作镜像，或换成相近的值；生成器最先列出的干扰项予以保留。其他选项随机打乱。
