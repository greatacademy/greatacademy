# 计费

> [English](billing.md) | 简体中文

Great Academy 只提供付费服务：只有订阅覆盖了某个学科，学习者才能学习这个学科。没有免费版，也没有试用；作为替代，每个账号的第一笔付款如果是月付，在 30 天内可以全额退款。计费是[路线图](roadmap.zh-CN.md)的 P9 阶段。它同时用来证明监护人是成年人，这是[未成年人数据](minors-data.zh-CN.md) §6 的要求。

## 1. 方案与价格

价格按每位学习者计算，以美元计：

| 方案 | 覆盖范围 | 按月 | 按年 |
| :--- | :--- | :--- | :--- |
| 单学科 | 一个学科，例如数学 | $19 | $199 |
| 全部学科 | 所有学科，包括以后新增的 | $49 | $499 |

- 按年价格比十二个月约低 15%。
- 总包比两个学科贵；它面向三门及以上学科的目录，上线前会达到。总包涨价时，已订阅者保持开始时的价格。
- 一位学习者可以同时持有多个方案；任何覆盖某学科的方案都能让其学习该学科。
- 已有单学科方案的学习者通过升级换成总包（§5）。降级和多个孩子的折扣以后再做。

## 2. 谁来付款

- **只有成年人付款。**成年人为自己、为自己添加的孩子、以及关注自己的青少年付款。
- **儿童。**监护人先为孩子购买方案，再添加孩子；方案在未分配状态等待，分配给其添加的下一个孩子。
- **青少年。**青少年和以前一样自行注册，但不能付款。他们的账号会显示一个邀请监护人的代码（[未成年人数据](minors-data.zh-CN.md) §6）。监护人用它关注这位青少年，并为其购买方案。
- 付款人管理方案：取消、申请退款、查看收据。学习者只能看到自己是否被覆盖。

## 3. 账户与支付方式

付款通过一个 Stripe 账户进行，名为 Great Academy，属于美国公司的 Stripe 组织。独立的账户名让付款人在 Checkout、收据和账单上看到正确的名称，也让它的付款与公司的其他产品分开。

| 支付方式 | 续费 |
| :--- | :--- |
| **银行卡**，包括 Stripe 随卡提供的钱包 | 自动续费，每月或每年到期时续费，直到取消 |
| **支付宝或微信支付** | 不续费：一次付款购买一个月或一年，到期前再付一次就再延长一期 |

Stripe Checkout 不能为支付宝或微信支付自动续费，所以它们按期购买。到期前七天，付款人会收到邮件：银行卡方案说明将会续费以及如何取消；钱包方案说明除非再次付款，否则访问将结束。

价格以金额而不是 Stripe 价格 id 传给 Checkout，所以上表是唯一的来源。销售税由 Stripe Tax 在公司已登记的地方计算；开启它是部署设置。

## 4. 注册

注册先问谁来学习（[未成年人数据](minors-data.zh-CN.md) §6），然后问年龄，再创建账号。接着显示方案，可以在按月和按年之间切换，并选择银行卡或支付宝、微信支付。付款前要勾选三个复选框，每个都是一句用我们自己的话写的独立声明：

1. 我已成年，并同意服务条款。
2. 我授权 Great Academy 在我取消之前续订方案并从我的银行卡扣款，我随时可以在线取消。钱包付款则改为说明不会续费。
3. 我要求方案立即开始，并知道开始后即放弃法律规定的撤回权（如适用）；只有我的第一笔付款且为月付时，可以在 30 天内退款。付款不能退款时，这句声明改为说明不能退款。

三个都勾选之前，按钮不可用。方案上方说明这个账号是否还有退款机会；选择按年时，说明年付不能退款、第一个月可以退款。学习者已有的学科（单独或包含在全部学科中）显示为已拥有，不能选择；在已有付款人付费的单学科方案时选择全部学科，会显示升级明细：价格、剩余时间的抵扣、今天支付的金额，以及原方案随之结束（§5）。“设置”在每个进行中的单学科方案上提供升级入口。Checkout 在 Stripe 的页面上进行，完成后回到方案页面，由它等待付款到账。

## 5. 取消与退款

- **取消。**银行卡方案停止续费，并持续到已付期限结束。钱包方案没有需要取消的东西。
- **退款。**每个账号有一次退款机会：账号的第一笔付款如果购买的是一个月（单学科或全部学科，银行卡或钱包），在付款后 30 天内可以从账号设置中申请全额退款；访问立即结束。年付、续费以及之后的任何付款都不退款，也不按比例退款。每个付款人一次退款，限定了退款的成本（Stripe 保留的手续费和一个月的使用），也杜绝了反复购买再退款来免费学习。
- **升级。**为已有同一付款人付费、仍在进行中的单学科方案（不含赠送和已退款的方案）的学习者购买全部学科，就是升级。每个这样的方案的价值是其最后一期的价格乘以该期尚未用完的比例；总和从第一笔付款中扣除：银行卡订阅用一次性的 Stripe 优惠券，钱包付款直接减少金额；续费按全价。付款到账后原方案结束：银行卡订阅在 Stripe 取消且不按比例退款，钱包方案立即结束。结束的方案不能再退款，所以当升级会放弃账号的退款机会时，明细会说明。抵扣后若不足 Stripe 的最低扣款 $0.50（例如年付单学科升级到按月总包），服务器拒绝，页面请付款人选择按年。抵扣是对原方案的唯一补偿。
- **撤回。**方案应付款人的要求在付款后立即开始，第三句声明记录法律规定的撤回期随之结束。服务条款保留付款人所在地法律不允许放弃的一切权利；上线前由律师按市场审阅措辞。
- **重复购买。**服务器拒绝为学习者已有的学科（单独或包含在全部学科中）再购买方案。
- 付款信息和换卡通过 Stripe 客户门户处理。

## 6. 访问

只要有覆盖某学科的方案已付至当前时间之后，学习者就可以学习该学科。每个学习请求都会在 `accessOf` 的年龄和同意规则之外检查这一点；监护人查看孩子的进度不需要方案。只有设置了账户的密钥后计费才生效：在本地没有它时，所有人都可以像以前一样学习。

管理员可以不经付款授予一段时间的方案，用于测试人员、审核人员和英语试点（[管理后台](admin.zh-CN.md)）。

## 7. 监护人验证

银行卡交易是[未成年人数据](minors-data.zh-CN.md) §6 首选的方法：发卡行会就每笔扣款通知持卡人。监护人第一笔已付的银行卡付款会使其验证通过，除非是预付卡，因为孩子也可能持有预付卡。钱包付款、预付卡或授予都不能验证；这样的监护人需要寄送签字表格，它仍然是兜底方式。之后的退款不会撤销验证，因为扣款已经发生并已通知；这一点请律师确认。

## 8. 移动应用

应用内不出售任何东西，也不显示价格或付款链接。没有方案的学习者会看到该账号没有该学科的方案。商店对于"让用户使用在别处购买的内容"的应用的规定，可能要求提供应用内购买；这一点在应用发布前决定。

## 9. 数据

| 表 | 保存内容 |
| :--- | :--- |
| `subscription` | 每个方案一行：付款人、学习者（等待孩子时为空）、范围（学科 id 或 `all`）、周期、付款方式（银行卡、钱包或赠送）、Stripe 订阅 id、已付至时间、取消、退款、上次提醒 |
| `payment` | 每笔扣款一行：方案、付款方式、Stripe payment intent、金额、币种、时间、是否为该方案的首次付款、退款时间 |

我们不保存任何银行卡信息。Stripe 的事件到达一个 webhook，读取任何内容前都先校验签名。

## 10. 配置

Worker 读取四个密钥（`apps/web/cloudflare.config.ts`）：

| 密钥 | 内容 |
| :--- | :--- |
| `STRIPE_SECRET_KEY` | 账户的密钥。只有它和 webhook 密钥都设置后计费才开启 |
| `STRIPE_WEBHOOK_SECRET` | 端点 `https://greatacademy.dev/api/stripe` 的签名密钥 |
| `STRIPE_WALLET` | 账户开通支付宝和微信支付后设为 `on`；在此之前方案页面只提供银行卡 |
| `STRIPE_TAX` | 为 `on` 时为银行卡方案开启 Stripe Tax |

端点监听 `checkout.session.completed`、`checkout.session.async_payment_succeeded`、`invoice.paid`、`customer.subscription.updated` 和 `customer.subscription.deleted`。客户门户允许更换银行卡和查看发票；取消和退款通过“设置”进行，以保证 30 天规则。设置 `STRIPE_WALLET` 之前，先在账户的支付方式中开通支付宝和微信支付。服务条款在 `/legal/terms`。删除账号会立即结束其付费的银行卡方案。
