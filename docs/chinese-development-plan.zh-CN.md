# 中文开发计划

> [English](chinese-development-plan.md) | 简体中文

本文把[中文课程体系](chinese-curriculum.zh-CN.md)中的设计拆成里程碑：建什么、改哪些文件、每一项怎样检验，以及哪些结果允许进入下一阶段。设计文档说明中文学科是什么，本文说明按什么顺序把它建出来。它仿照[英语开发计划](english-development-plan.zh-CN.md)，并复用英语已经建好的东西。

---

## 1. 工作怎样组织

| 阶段 | 交付 | 需要外部提供 | 结束于 |
| :--- | :--- | :--- | :--- |
| 0 准备 | 记录内容来源，部署 Worker，回答法律和供应商问题 | 律师、审阅者 | 闸门 CG0 |

```text
CG0 ─► C1 第一切片 ─► CG1 ─┬─► C2 一至三级 ─► CG2 ─┬─► C6 四至九级、写作、口语、考试
                           ├─► C3 手写 ─► CG3 ─────┼─► C4 一、二年级、华裔
                           └─► C5 七至九年级、高中、文言（只有写字主题依赖 C3）
```

**每个里程碑都遵守的规则。**

- 每个阶段都不影响数学和英语：它们的测试、Worker 和学习者状态保持原样。
- 核心库不涉及具体学科。只有中文需要的东西放在 `libs/subject-chinese` 和 `content/chinese`。
- 内容为本学科编写。从不照搬教材的课文和习题；古诗文属于公有领域（[设计 §13](chinese-curriculum.zh-CN.md#13-内容来源与权利)）。
- **需要人参与的工作不阻塞不需要人的工作。** 内容先写好、通过测试和审计、接入系统；教师审阅、法律意见、账号和试点在有人时再做（§9.3）。在本阶段要求的审阅完成之前，任何内容都不面向学习者。
- 工作按规模而不是按日期估计：**S** 是一个包里的几次提交，**M** 跨几个包，**L** 是大量内容或一种新输入。
- 每个里程碑同时更新它所改动的文档的两种语言版本。一个阶段完成后更新[路线图](roadmap.zh-CN.md)。

## 4. 阶段 2：外语一至三级

| 工作 | 文件 |
| :--- | :--- |
| 拼音数据：每一级的音节、声母、韵母和声调 | 新增 `content/chinese/src/pinyin` |
| 声调、声母、韵母、音节和标调的主题：先听辨选择，再输入 | `content/chinese` |
| 用声调数字或调号输入拼音，由 `pinyin` 判定 | `libs/subject-chinese`（已完成） |
| 变调：“一”“不”和两个三声相连，听辨和识别；书写仍用原调 | `content/chinese` |

**已完成的部分。** 不需要音频的部分，即课程 `chinese-pinyin`：`pinyin` 分支的 6 个主题、12 个知识点，题目取自三至六年级汉字读音中的 686 个音节。内容包括声调和调号的位置、声母、韵母、y、w、ü 的拼写规则和 iu、ui、un 的省写，以及“一”“不”和两个三声相连时的读法和写法。听辨和拼音输入随录音加入。

### C2.2 一至三级的汉字、词语和语法（L）

| 部分 | 规模 | 形式 |
| :--- | :--- | :--- |
| 汉字主题 | 90 批，每批 10 字（900 字） | 字形、字音和字义：字义用学习者的界面语言，读音用拼音 |
| 词语主题 | 约 225 批，每批 10 个（2,245 个词） | 词义、在句子中运用、拼音 |
| 语法点 | 210 个，大多一个语法点一个主题 | 选择和排序，用给定的词组句 |
| 课程 `chinese-level-1` 至 `chinese-level-3` | 日常生活的主题单元 | [设计 §8.3 和 §8.4](chinese-curriculum.zh-CN.md#83-外语课程) |

字和词取自律师认可的表（C0.2）；在此之前按标准的等级编排，与母语识字批次按附录 5 编排相同。

**目前已建。** 一级，即课程 `chinese-level-1`（[大纲](chinese-courses/chinese-level-1.zh-CN.md)）：300 个字分 30 个主题，学字形、读音和字义；500 个词分 50 个主题，学词义、读音和运用；分十二个主题单元，从问候到健康。每个句子只用已经学过的字，内容在构建时检查这一点。这些字按日常生活中最常用的选出；还需要对照 GF 0025-2021 的一级字表核对，并由教师审读句子。二级，即课程 `chinese-level-2`（[大纲](chinese-courses/chinese-level-2.zh-CN.md)），在一级之后：再学 300 个字，分 30 个主题；770 个词，分 77 个主题；分十二个单元，从日常作息到节日，写法相同；这些字按接近标准二、三级的范围选出，等待同样的核对。三级，即课程 `chinese-level-3`（[大纲](chinese-courses/chinese-level-3.zh-CN.md)），在二级之后：再学 300 个字，分 30 个主题；970 个词，分 97 个主题；分十二个单元，从观点和理由到生活方式；不少常用字在三级之后才学，所以个别词不如教师会选的那样常用，同样等待核对。语法点尚未编写。

### C2.3 听力（M）

| 工作 | 文件 |
| :--- | :--- |
| 用 Azure 神经语音（成人和儿童音色），通过现有的音频工具，事先录好音节、词语、句子和对话 | `tools/audio` |
| 听力主题：选出听到的音节、声调、词语或意思 | `content/chinese` |

录音在部署本学科时随学科的其他音频一起上传（C0.4）。

**已完成的部分。** `content/chinese/src/audio.ts` 构造音节、词语和句子的 SSML，由 `zh-CN-XiaoxiaoNeural` 以比常速慢 10% 的速度朗读；音节由一个有此读音的字承载，声调用 SAPI 音素固定（ü 写作 v）。`tools/audio` 支持 `--subject chinese`，主题 `pinyin-hearing` 的 71 条录音已生成：在一个音节的四个声调中听出它的声调，分辨读音相近的声母和韵母（zh 和 z、n 和 l、f 和 h、an 和 ang、in 和 ing）。题目播放尚未生成的录音时测试失败。讯飞对单个音节的评测无论哪个音色朗读，都把部分第三声判为错误，所以不能用它检验录音：录音发布前由老师试听。词语、句子和对话录音随一至三级课程制作。

### C2.4 口语（M）

| 工作 | 文件 |
| :--- | :--- |
| 在 Azure 之外增加讯飞发音评测的提供方，逐个音节报告声调、声母或韵母是否错误 | `libs/judge` |
| `zh-CN` 口语题：跟读音节、词语和句子 | `content/chinese` |
| 和所有 AI 及语音供应商一样，由管理员选择提供方 | `apps/web` 管理后台 |

**已完成的部分。** provider：`libs/judge` 中的 `iflytekSpeech`，由讯飞的基础 URL 选用，对照参考文本评测 `zh-CN` 录音，给出每个音节的拼音和读错的部分。管理员只能把它用于 `pronunciation:zh-CN` 路由，它已在试验的录音上对真实服务跑通。语音判定器把每个汉字当作一个词，读错的音节连同读错的部分一起点出，如“好（声母、声调）”。第一个口语主题 `pinyin-saying` 是拼音课的最后一个主题：跟着录音说双音节词语，45 个练声调组合，59 个练说话时的变调（两个第三声相连、“一”和“不”）。句子随一至三级加入。

用故意读错的合成录音做的试验发现：讯飞的儿童模式能标出约 80% 的单个声调错误，Azure 约 50%；讯飞还能标出 Azure 判为正确的声母和韵母错误。阈值是*起始*值，依赖它们之前要用真实学习者的录音确认。

**闸门 CG2。** 一至三级的学习者在外部测试中有进步，并且在一批真实录音上，发音反馈与教师的判断一致。

## 6. 阶段 4：一、二年级和华裔衔接课

笔画和部件、300 个基本字、先识字后学拼音、儿歌和短诗、最初的句子；课程 `chinese-grade-1` 和 `chinese-grade-2`。衔接课 `chinese-heritage-1` 至 `chinese-heritage-3` 是母语图谱上的视图，只有少量自己的主题（[§8.2](chinese-curriculum.zh-CN.md#82-华裔课程)）。

**已完成。** 一、二年级的识字：字表一中三至六年级不教的 1600 个字，常用的在前，每字三个词语和形近字，分成 133 个主题，含认读和书写（`recognizing-characters-1-01` 至 `recognizing-characters-2-66`）。二十首背诵短诗，每年级十首，选自课标推荐篇目。笔画和笔顺三个主题、偏旁部首三个主题，在有笔画数据之前用选择题检查。课程 `chinese-grade-1`（[大纲](chinese-courses/chinese-grade-1.zh-CN.md)）含用中文讲解的 `chinese-pinyin` 拼音内容，`chinese-grade-2`（[大纲](chinese-courses/chinese-grade-2.zh-CN.md)）是三年级的前置课程。华裔识字衔接课 `chinese-heritage-1` 至 `chinese-heritage-3`（[大纲](chinese-courses/chinese-heritage-1.zh-CN.md)）把一至四年级的识字批次排成 600、1600 和 2500 字三段，第一门含拼音、笔画和偏旁，另有六个自有主题：同音字，“的、地、得”和代词，词语和成语的写法，方言词和普通话，口语和书面语，繁体字。每个年级四批词语，共四十个日常词语。阅读：六个单元，每单元三篇，其中有儿歌，都用本年级学过的字写成。华裔衔接课的阅读：每门衔接课两个单元，每单元三篇，为年龄较大的学习者而写，只用该课已教的字。句子和手写尚待完成。多音字取的最常用读音、主读音为轻声的语气词，以及少数词语较弱的字，留待教师审读。

## 7. 阶段 5：七至九年级、高中和文言

附录 5 字表二的其余部分、文言文及其虚词、议论和说明、七至九年级的 60 篇和高中的 72 篇背诵篇目，以及 `chinese-hs-required` 和 `chinese-hs-selective`。文言文属于公有领域；现代文为本学科编写。

**已建成。** 七至九年级，即课程 `chinese-grade-7` 到 `chinese-grade-9`（[大纲](chinese-courses/chinese-grade-7.zh-CN.md)），共 132 个主题、348 个知识点：小学不教的字表二中的 500 个字，分 42 批识字，九年级结束时达到 3500 个常用字；每个年级四批词语和四批成语；借代、对比、引用、顶真四种修辞，句式杂糅和不合逻辑的病句；60 篇背诵篇目，每个年级十二首古诗词和八篇文言文；以及三个文言练习：实词、“其”和“为”、通假字。高中，即课程 `chinese-hs-required` 和 `chinese-hs-selective`（[大纲](chinese-courses/chinese-hs-required.zh-CN.md)），共 98 个主题、284 个知识点：每门课四批词语和四批成语；通感、互文、双关、反语，表意不明的病句；72 篇背诵篇目，每门课二十首古诗词曲和十六篇文言文；以及八个文言练习：虚词“乃”“且”“若”“焉”“何”“乎”“因”“与”“则”“所”“也”“者”、文言特殊句式、词类活用和古今异义。七至九年级的阅读：九个单元，每单元三篇，每个年级一个记叙文单元、一个说明文单元、一个议论文单元，并考查说明方法和论证方法。高中的阅读：六个单元，每单元三篇，每门课一个论述类、一个实用类、一个文学类单元。多音字的读音和少数词语等待教师审阅。

## 8. 阶段 6：四至九级、写作、口语和会话、考试

四至九级延续 C2。AI 评判的写作复用 `libs/judge`，校准集由语文教师打分；会话复用语音服务。考试课程 `chinese-hsk-1` 至 `chinese-hsk-7-9` 和 `chinese-gaokao` 在它们所考的课程之后建设。

**已建成。** 四级，即课程 `chinese-level-4`（[大纲](chinese-courses/chinese-level-4.zh-CN.md)），建立在三级之上：再学 300 个汉字（30 个主题）和 1000 个词语（100 个主题），分十二个单元，从健康和医疗到职业，写法与一至三级相同。一至三级没有教的一些很常用的字，如“始”“主”“之”“与”，放在需要它们的单元里教；仍需对照 GF 0025-2021 四级核对这些字，并由教师审读句子。五级，即 `chinese-level-5`（[大纲](chinese-courses/chinese-level-5.zh-CN.md)），建立在四级之上：再学 300 个汉字（30 个主题）和 1070 个词语（107 个主题），分十二个单元，从社会到价值和观念，又补上前几级没有教的一些常用字，以及国名和作家名字里需要的字；同样的核对仍待完成。六级，即 `chinese-level-6`（[大纲](chinese-courses/chinese-level-6.zh-CN.md)），建立在五级之上：再学 300 个汉字（30 个主题）和 1140 个词语（114 个主题），分十二个单元，从语言和交流到思考和论证，先教前几级漏掉的“或”“它”“青”“派”“令”“似”“若”；同样的核对仍待完成，有些中文释义还用到尚未教的字。七级，即 `chinese-level-7`（[大纲](chinese-courses/chinese-level-7.zh-CN.md)），取高等最常用的三分之一：再学 400 个汉字（40 个主题）和 1880 个词语（188 个主题），分十二个单元，从社会变迁到经济和贸易；同样的核对仍待完成。八级，即 `chinese-level-8`（[大纲](chinese-courses/chinese-level-8.zh-CN.md)），取中间的三分之一：再学 400 个汉字和 1880 个词语，共 228 个主题，分十二个单元，从社区和社会问题到金融和市场；同样的核对仍待完成。九级，即 `chinese-level-9`（[大纲](chinese-courses/chinese-level-9.zh-CN.md)），取最后的三分之一，学完高等：再学 400 个汉字和 1880 个词语，共 228 个主题，分十二个单元，从语言和修辞到公文和应用文；同样的核对仍待完成。HSK 课程 `chinese-hsk-1` 至 `chinese-hsk-6` 和 `chinese-hsk-7-9`（[HSK 1](chinese-courses/chinese-hsk-1.zh-CN.md) 至 [HSK 7–9](chinese-courses/chinese-hsk-7-9.zh-CN.md)），每门包含它所考等级的单元和三个只练习的考试主题，把整个等级混在一起练：五选一或六选一的选词填空、两个方向的词语和意思、在形近字中选字；试卷题型还待确认（§9.3），听力、口语和写作在有了音频和评判之后加入。高考课程 `chinese-gaokao`（[大纲](chinese-courses/chinese-gaokao.zh-CN.md)），包含两门高中课程的单元和三个只练习的考试主题，把七至十一年级的内容混在一起：成语辨析、情景式默写和文言字词；现代文阅读在有了评判之后加入。母语三至六年级的 AI 评判习作，每个年级两个主题，作为“习作”单元加进年级课程：围绕一个意思写一段话和观察日记，把一件事的起因、经过、结果写清楚和书信，通过事例写出人物特点和按特点介绍一种事物，用事例证明观点和写景时融入感情。每个主题有十二道为本学科编写的题目和范文，以及三条是非式评判标准，放在 `libs/subject-chinese`；提示词 `writing-zh-1` 要求评判按汉字计算长度，并用简体中文给出反馈。长度按字计算，从三年级的 100 字到六年级的 400 字。七至十一年级照此继续，每个年级两种写作加进课程：记叙文的中心和细节，说明的顺序和演讲稿，议论文和完整的记叙文，任务驱动型材料作文和时评，辩证分析和倡议书；高考课程增加一个只练习的作文主题，根据原创材料写不少于 800 字的文章。这些标准等待中文教师评分的校准集（§9.3），并由管理员配置路由之后才面向学习者。

### 9.4 什么会让计划停下

- **CG1 未通过：** 在弄清方法之前不再增加内容。
- **律师不允许使用某个表：** 用可以使用的来源重新编排由它生成的内容；保留学习者已持有的 id。
- **发音评测与教师不一致：** 口语只作练习，不打分；声调通过听力来教。
- **没有可用的笔画数据：** 写字主题等待，一、二年级不开放。
